# AttendHour 📊

A modern **Department Attendance Management System** for tracking student attendance with real-time analytics and comprehensive reporting.

---

## 🌟 Features

- **Attendance Tracking** - Real-time student attendance marking and management
- **Dashboard Analytics** - Interactive charts and statistics for attendance patterns
- **Department Management** - Organize and manage attendance by departments
- **Progress Monitoring** - Track attendance trends and identify patterns
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **PWA Support** - Install as a web app for offline access
- **Testing Suite** - Comprehensive unit and integration tests

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **HTTP Client:** Axios
- **Charts & Visualization:** Recharts
- **Routing:** React Router DOM
- **PWA:** Vite Plugin PWA
- **Testing:** Vitest & React Testing Library
- **Package Manager:** npm

---

## 📦 Installation

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SENAPATHINAGENDRA1226/AttendHour.git
   cd AttendHour
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:5173`
